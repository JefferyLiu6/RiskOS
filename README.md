# RiskOS

**A credit risk, expected-credit-loss, and model governance platform.**

## Scope and framing

> The underlying portfolio is U.S. residential mortgage data, because comparable
> public Canadian loan-level default and loss data is not available. The project
> applies IFRS 9 concepts and OSFI Guideline E-23 as a methodological and
> governance framework relevant to Canadian financial institutions. It does not
> represent a regulatory implementation, does not reproduce any institution's ECL
> system, and makes no claim of OSFI compliance.

The review artifact is a **developer validation with simulated second-line
review**. True organizational independence cannot be reproduced in a solo
project, and that is recorded as a limitation of the review rather than of the
model.

## Getting the data

Access is **manual**. Freddie Mac moved distribution to Clarity Data
Intelligence, which requires free registration. There is no scraper in this repo
and there will not be one.

1. Register at Clarity Data Intelligence and accept the SFLLD licence terms.
2. Download the **sample** dataset (50,000 loans per vintage year), not the full
   dataset, for vintages **1999–2012** and **2015–2019**. Each vintage year has
   an origination file and a performance file, pipe-delimited, no header row.
3. Download the *Single Family Loan-Level Dataset General User Guide* that ships
   with the data.
4. Unpack everything into `data/raw/`. The whole `data/` tree is gitignored;
   raw and derived loan-level data are never committed.
5. Record the User Guide version and column layout in `conf/data.yaml`. Ingest
   refuses to run while `layout.version` is null — column positions are taken
   from the guide, never from memory.

FRED access needs a free API key in `.env` (see `.env.example`).

## Setup

```bash
make setup     # uv sync
make test
```

## Layout

```
conf/          typed YAML config — every numeric assumption lives here, never in code
governance/    model inventory, risk assessment, findings register, approval record
docs/          guide book, one chapter per phase
src/riskos/    ingest, features, models, metrics, ecl, monitor, serve
tests/         unit tests, including leakage assertions
reports/       validation report and model cards (generated Markdown, Quarto-renderable), selection memo, figures
data/          gitignored
```

`make` targets: `setup ingest panel features train challenger evaluate hazard ecl monitor registry serve report test lint all`.

## Intended use

Illustrative and educational. **Not** for real lending or underwriting decisions,
**not** for regulatory capital or provisioning, and not applicable to any
Canadian portfolio without redevelopment on Canadian data.
